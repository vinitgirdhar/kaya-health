Can I use Kaya on an iPhone?

Kaya currently supports Android only. An iPhone cannot install this APK.

What should I know about this download?

This is a debug-signed build for testing, built from the app source. A future release signed with a different key may require uninstalling it first. Use Kaya’s backup feature before uninstalling if you want to retain your data.

Do I need a Noise REP band?

A Noise REP is needed for band readings and syncing. Other Noise models are untested. Food logging, habits, and manual entries can be explored without a band.
